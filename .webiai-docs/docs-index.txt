Usage:
  webiai docs <document>              Show document content
  webiai docs <directory>             List documents in directory

Examples:
  webiai docs agents.md               CLI and SDK guide
  webiai docs cli/agents.md           CLI agent guide
  webiai docs cli/sst/agents.md       SST commands agent guide
  webiai docs cli/sst/dev.md          Show dev command documentation
  webiai docs cli/sst/state/find.md   Show state find documentation
