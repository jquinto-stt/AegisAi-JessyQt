# webiai sst logs tail

Tails SST or function log files with optional follow mode.

## Usage

    webiai sst logs tail <type> [options]

## Arguments

| Argument | Description | Required |
|----------|-------------|----------|
| `<type>` | Log type: `sst`, `function`, or `fn` | Yes |

## Options

| Option | Description | Default |
|--------|-------------|---------|
| `-n, --lines <N>` | Number of lines to display | `20` |
| `-f, --follow` | Follow mode — wait for new lines | `false` |
| `--dir <path>` | Log directory | `.sst/log/webiai` |

## Type Aliases

| Input | Resolves To |
|-------|-------------|
| `sst` | `sst.log` |
| `function` | `function.log` |
| `fn` | `function.log` |

## Examples

    # Last 20 lines of SST logs
    webiai sst logs tail sst

    # Last 50 lines of function logs
    webiai sst logs tail fn -n 50

    # Follow SST logs in real-time
    webiai sst logs tail sst -f

    # Follow function logs with initial 100 lines
    webiai sst logs tail function -f -n 100

## Notes

- Log files are generated by `webiai sst dev` or `webiai sst logs filter`.
- If the log file doesn't exist, the command exits with an error suggesting to run `sst:dev:mono` first.
- In follow mode, the file is polled every 200ms for new content.
- If the file is truncated (new run), the offset resets automatically.
