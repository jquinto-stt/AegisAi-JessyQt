Usage: webiai [options] [command]

WebIAI CLI

Options:
  -V, --version               output the version number
  -h, --help                  display help for command

Commands:
  infra                       Infrastructure lifecycle commands
  docs [document]             Display embedded documentation
  init [options]              Bootstrap the CLI into this project
  install [options]           Install SDK packages and project dependencies
  run                         Run workflow commands (build, test, clean, dev)
  hooks [options] [hooks...]  Sync managed scripts: build hooks + dev scripts
                              (from any monorepo level)
  build [options]             Sync hooks and run build (from any monorepo level)
  tests [options]             Sync hooks and run tests (from any monorepo level)
  clean [options]             Sync hooks and run clean (from any monorepo level)
  scan [options]              Inspect monorepo structure, artifacts, and
                              configuration
  project                     Project-level commands
  lib                         Manage library artifacts
  bundle                      Manage bundle artifacts
  dev [options]               Run artifact in dev mode (auto-detects bundle
                              artifact)
  kiro                        Kiro agent management
  help [command]              display help for command

📚 Documentation:
   webiai docs              Browse documentation
   webiai docs agents.md    CLI and SDK guide
   webiai docs cli          CLI command reference

🤖 AI Agents:
   Start with "webiai docs agents.md" for the root guide.
   Each directory has an agents.md with context for that level.
   Navigate deeper: cli/agents.md → cli/sst/agents.md → cli/sst/<group>/agents.md
